# Reference

These pages are the _reference_ for Archcare: the _what_, not the _why_. They document the
contracts Archcare upholds, not the design decisions that led to those exact shapes. The
[architecture pages](../architecture/index.md) explain the _design_, the
[guides](../guides/index.md) explain the _workflow_, and the pages here document the _contract_:
every TOML key, every CLI command, and every public API member.
